# Common Playground Perugia

This repository contains the website for Common Playground Perugia.

## Project structure

- The public website is located in `/docs`.
- HTML files are located in `/docs`.
- CSS files are located in `/docs/css`.
- JavaScript files are located in `/docs/js`.
- Fonts are located in `/docs/assets/fonts`.
- Images are located in `/docs/assets/images`.
- Icons are located in `/docs/assets/icons`.

## Development rules

- Use semantic HTML.
- Keep HTML, CSS and JavaScript separated.
- Use relative paths for internal files and assets.
- Do not introduce frameworks or external dependencies unless explicitly requested.
- Do not modify unrelated parts of the project when implementing a specific task.
- The website must remain compatible with GitHub Pages.

## Design

- Follow the supplied Figma layouts as closely as possible.
- Desktop and mobile layouts must both be implemented.
- Do not invent visual elements that are not present in the supplied design.
